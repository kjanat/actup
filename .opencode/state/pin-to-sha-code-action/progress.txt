## Codebase Patterns

- `CheckResult` uses builder pattern: `CheckResult::new(...).with_resolved_sha(sha)`
- `version::Version::parse("main")` → `Other { tag }`, NOT `Branch`. Handle both `Branch` and `Other` when checking default_branch.
- No `is_full_semver()` on Version — pattern match `Semver { minor: Some(_), patch: Some(_), .. }` instead.
- `Sha40` type wraps validated 40-char hex; use `.to_string()` to get `String` for `resolved_sha`.
- `resolve_ref_to_sha` returns `Result<Sha40>` — async provider call, use sparingly.
- Sync SHA resolution: check `semver_tags` (exact version match), `major_tags` (major-only), `default_branch` (name match).
- Async SHA resolution: `resolve_ref_to_sha` fills gaps (non-default branches, unusual tags).
