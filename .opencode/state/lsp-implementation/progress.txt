## Codebase Patterns

### Core Integration
- Use `actup_core::extract_uses_from_yaml()` for parsing (returns `Vec<UsesLocation>`)
- Use `actup_core::check_action()` for version resolution (returns `CheckResult`)
- Use `actup_core::provider::Registry` for multi-provider support
- Use `actup_core::Config` for policy/ignore settings

### Edit Patterns (from CLI)
- `PendingEdit::replace_ref(line, old_ref, new_ref)` for ref updates
- `FileEdits` for accumulating edits per file
- Preserve trailing newlines and formatting

### Error Classification
- `Error::is_environment_error()` distinguishes user vs env errors
- User errors (NotFound, InvalidRef) -> Error severity
- Env errors (Network, RateLimit, Auth) -> Information severity + status message

### tower-lsp-server 0.23 Patterns
- Crate re-exports `ls_types` (not `lsp_types`) — use `tower_lsp_server::ls_types::*`
- Store `Client` handle in backend for async notifications
- `LspService::new(|client| Backend::new(client))` constructor pattern
- `Server::new(stdin, stdout, socket).serve(service).await` for stdio transport
- Use `DashMap` for concurrent document access
- Spawn background tasks with `tokio::spawn`
- Check client capabilities before using features
- `InitializeResult` has only 2 non-feature-gated fields: `capabilities` + `server_info`
- Tracing must write to stderr (stdout is the LSP transport)
- `Uri` has no `Display` — use `uri.as_str()` in tracing fields, not `%uri`
- `Uri::to_file_path()` returns `Option<Cow<'_, Path>>` — call `.into_owned()` for `PathBuf`
- `Uri::from_file_path(path)` returns `Option<Uri>` — useful in tests

### Config Loading
- `Config::load(config_path, start_dir)` — layered (env > explicit > repo > user > defaults)
- `Config::discover(start_dir)` — never fails, convenience wrapper
- `config.policy_for(owner, repo)` / `config.should_ignore(owner, repo, ref_str)` for per-action queries
- Use `tokio::sync::RwLock<Config>` for async-safe interior mutability (future config reload)
